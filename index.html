How billing works

      
You pay for results, not for attempts

    

    

      

        no-data → $0
        
Failures are free

        
Items that fail, return no data or have no speech are never charged. A Trends term with too little search volume costs nothing.

      

      

        Max cost per run
        
Set a spending cap

        
Give each run a maximum cost. The Actor stops cleanly at that limit and keeps everything it already delivered.

      

      

        RESUME_STATE
        
Never charged twice

        
If the platform restarts a long run, finished items are skipped, so you never pay for the same result again.
