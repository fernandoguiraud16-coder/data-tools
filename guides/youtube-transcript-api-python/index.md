# YouTube transcript API for Python

Libraries like `youtube-transcript-api` work on a laptop but get blocked ("Sign in to confirm you are not a bot") as soon as they run from a server or in volume. This tool runs the requests through rotating residential IPs and returns the transcript of any public video, Short, channel or playlist.

## What you get

- Plain text, timestamped segments, SRT, VTT, Markdown and RAG chunks.
- Whole channels (`@handle`) and playlists, newest first; "only new videos" for scheduled runs.
- Title, channel, views, duration and the caption language of every video.
- Optional Whisper AI transcription for videos without captions (`aiFallback`).

## Python example

```python
from apify_client import ApifyClient  # pip install apify-client

client = ApifyClient("<YOUR_APIFY_TOKEN>")
run = client.actor("fguiraud/youtube-transcript-scraper").call(run_input={
    "videos": [
        "https://youtu.be/arj7oStGLkU"
    ],
    "languages": [
        "en"
    ],
    "outputs": [
        "text",
        "segments"
    ]
})

for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item["title"], item.get("wordCount"))
    print(item.get("text", "")[:300])
```

No Python? Open the [Actor page](https://apify.com/fguiraud/youtube-transcript-scraper), paste your input in the form and press Start; results export to JSON, CSV or Excel.

## FAQ

**Do I need a YouTube API key?**

No. Only an Apify account; the free plan includes monthly credit.

**What if a video has no captions?**

The row says `no-captions`. Turn on `aiFallback` to transcribe the audio with Whisper.

**Can I get only the videos a channel posted since my last run?**

Yes: add the channel to `channels`, set `onlyNewVideos: true` and schedule the run.

**Can an AI agent use it?**

Yes. It is an MCP server at `https://mcp.apify.com/?tools=fguiraud/youtube-transcript-scraper` (listed in the official MCP registry), and there is an [agent skill](https://github.com/fernandoguiraud16-coder/data-tools/tree/main/skills) for Claude Code, Codex and Cursor. Field-name guesses such as `url` or `urls` are accepted.
