# youtube-transcript-api blocked on your server? A hosted fix

The `youtube-transcript-api` README says it plainly: YouTube blocks most IPs of cloud providers (AWS, Google Cloud, Azure...), so on a server you get `RequestBlocked` or `IpBlocked`, and the fix is rotating residential proxies. This tool already runs on rotating residential IPs, so the same transcripts come back without buying or configuring proxies.

## What you get

- Video links or IDs, Shorts, whole channels and playlists.
- Text, timestamped segments (like `fetch()`), SRT, VTT, Markdown, chunks.
- Language preference with fallback, manual vs auto-generated captions.
- Whisper AI fallback for videos without any captions.

## Python example

```python
from apify_client import ApifyClient  # pip install apify-client

client = ApifyClient("<YOUR_APIFY_TOKEN>")
run = client.actor("fguiraud/youtube-transcript-scraper").call(run_input={
    "videos": [
        "dQw4w9WgXcQ"
    ],
    "languages": [
        "en"
    ],
    "outputs": [
        "segments"
    ]
})

for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    for seg in item.get("segments", []):
        print(seg)
```

No Python? Open the [Actor page](https://apify.com/fguiraud/youtube-transcript-scraper), paste your input in the form and press Start; results export to JSON, CSV or Excel.

## FAQ

**Do I need to change much code?**

Replace the `fetch()` call with the client call above; `segments` has `start`, `end` and `text`.

**What about videos without captions?**

They return `no-captions`; turn on `aiFallback` to transcribe the audio.

**Can an AI agent use it?**

Yes. It is an MCP server at `https://mcp.apify.com/?tools=fguiraud/youtube-transcript-scraper` (listed in the official MCP registry), and there is an [agent skill](https://github.com/fernandoguiraud16-coder/data-tools/tree/main/skills) for Claude Code, Codex and Cursor. Field-name guesses such as `url` or `urls` are accepted.
